# EngPersona (Node.js)

Migrasi dari Laravel ke Node.js (Express + EJS + sql.js).

## Jalankan

```bash
npm install
npm start
```

Aplikasi berjalan di `http://localhost:3000`.

## Data

Database menggunakan file SQLite: `data/database.sqlite` (disalin dari proyek Laravel lama).
